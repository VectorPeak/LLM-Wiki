# Post-Class Update Checklist

Use this checklist after a real Mentor session.

## Required Updates

- [ ] Update `progress.md`.
- [ ] Archive stale progress into `session_archive.md`.
- [ ] Add book/material improvement notes to `book_revision_notes.md`.
- [ ] Add one diary entry to `diary.md`.
- [ ] Add persona group chat to `wechat_unread.md`.
- [ ] Update the active tutor persona if relationship/attitude changed.
- [ ] Append compact learning trace to `01.raw/02.DailyNotes/<current-range>.md` if meaningful.

## Input Type Update

- Concept input: update or create a mastery card if the concept will recur.
- Code input: record reusable bug patterns, edge cases, or interview variants.
- Question input: add the question to the question bank if it exposed a real gap.

## DailyNotes Entry Shape

Only include sections that actually have content.

```markdown
### Mentor

- Goal:
- Question:
- Concept:
- Code:
- Output:
- Feedback:
- Next:
```
