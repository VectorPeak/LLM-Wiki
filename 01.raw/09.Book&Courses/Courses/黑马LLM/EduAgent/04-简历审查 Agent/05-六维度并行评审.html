    4.5 六维度并行评审¶

    学习目标¶

    • 理解为什么六维度评分要**并行**，以及 asyncio.gather 如何把耗时从"相加"变成"取最大"
    • 掌握 run_six_dimensions 节点：并行发起评分、计算加权综合分、单维度失败降级
    • 理解维度定义表 SIX_DIMENSIONS（名称/权重/侧重）如何驱动评审
    • 写完即测：用假 LLM 离线验证并行、加权、降级（无需 Key）

    📁 本节要修改的文件：

    文件路径 作用 进度
    backend/agents/resume/nodes.py 追加 run_six_dimensions 节点及辅助 🔧 本节追加

    4.5.1 为什么要并行¶

    六维度评分，本质是**6 次相互独立的 LLM 调用**——项目深度怎么评，和技术匹配度怎么评，互不依赖。

    如果**串行**（一个评完再评下一个），每次 LLM 约 5–10 秒，6 个就是 30–60 秒，用户要干等。但既然它们互相独立，完全可以**同时发出去**——这正是 2.1 学的 asyncio.gather：把 6 个协程一起 await，总耗时约等于"最慢的那一个"（5–10 秒），而不是 6 个相加。

    串行：评1 → 评2 → 评3 → 评4 → 评5 → 评6     （总耗时 = 6 次相加）

并行：评1 ┐
      评2 ┤
      评3 ┤
      评4 ┤  asyncio.gather 同时进行          （总耗时 ≈ 最慢的 1 次）
      评5 ┤
      评6 ┘

    这就是本节是"性能重点"的原因——一个 gather 把这个 Agent 最慢的环节提速近 6 倍。

    4.5.2 六维度定义表¶

    先用一张表定义六个维度——每个维度有标识 key、中文名 name、权重 weight、评审侧重 focus。权重之和正好是 1.0，用于最后算加权综合分：

    SIX_DIMENSIONS = [
    {"key": "project_depth",  "name": "项目深度",   "weight": 0.30, "focus": "..."},
    {"key": "tech_match",     "name": "技术匹配度", "weight": 0.25, "focus": "..."},
    {"key": "expression",     "name": "表达规范性", "weight": 0.15, "focus": "..."},
    {"key": "structure",      "name": "简历结构",   "weight": 0.15, "focus": "..."},
    {"key": "quantification", "name": "量化程度",   "weight": 0.10, "focus": "..."},
    {"key": "authenticity",   "name": "真实可信度", "weight": 0.05, "focus": "..."},
]
    • key 用来从 4.3 的 DIMENSION_REVIEW_PROMPTS 字典里取对应提示；
    • name / weight 会被填进 DimensionScore（回顾 4.2："维度名和权重由代码填，LLM 只管打分"）；
    • focus 填进提示词的 {focus} 占位符，告诉 LLM 这个维度重点看什么；
    • 权重设计：项目深度（0.30）和技术匹配度（0.25）占大头——对工程师简历，这两项最关键。

    4.5.3 run_six_dimensions 节点¶

    节点内部分三步：① 准备结构化摘要 → ② 并行评 6 个维度 → ③ 算加权分。

    核心是内层函数 review_one_dimension + asyncio.gather：

    async def run_six_dimensions_node(state: ResumeState) -> dict:
    raw_text   = state["raw_text"]
    structured = state.get("structured") or {}
    structured_summary = _build_structured_summary(structured)   # 精简摘要，省 token

    async def review_one_dimension(dim: dict) -> dict:
        """评审单个维度，返回一条 DimensionScore dict。内含 2 次重试。"""
        prompt = DIMENSION_REVIEW_PROMPTS[dim["key"]].format(
            resume_text=raw_text[:3000],
            structured_summary=structured_summary,
            focus=dim["focus"],
        )
        for attempt in range(2):                  # 最多试 2 次
            try:
                structured_llm = get_structured_llm("resume", DimensionScore)
                result: DimensionScore = await structured_llm.ainvoke([
                    SystemMessage(content=SYSTEM_PROMPT),
                    HumanMessage(content=prompt),
                ])
                d = result.model_dump()
                d["dimension"] = dim["name"]      # 代码层填：中文维度名
                d["weight"]    = dim["weight"]    # 代码层填：权重
                d["key"]       = dim["key"]
                return d
            except Exception as e:
                if attempt == 0:
                    await asyncio.sleep(1)         # 第一次失败：等 1 秒重试
                else:
                    return _empty_dimension_score(dim)   # 第二次仍失败：降级为 50 分

    # ── 六维度并行 ──
    tasks = [review_one_dimension(dim) for dim in SIX_DIMENSIONS]
    dimension_scores = await asyncio.gather(*tasks)      # 同时跑 6 个，等全部完成

    # ── 加权综合分 = Σ(各维度得分 × 权重) ──
    weighted_score = sum(d["score"] * d["weight"] for d in dimension_scores)

    return {
        "dimension_scores": list(dimension_scores),
        "weighted_score":   round(weighted_score, 2),
    }

    几个关键点：

    • tasks = [review_one_dimension(dim) for dim in SIX_DIMENSIONS] 先创建 6 个协程（注意：此时还没执行，只是"准备好"）；
    • await asyncio.gather(*tasks) 把 6 个协程一起跑、等全部完成，返回结果列表（顺序与传入一致）；
    • 单维度失败不影响其他：每个维度自己 try/重试/降级，某个挂了只影响它自己（降级为 50 分并标记需复核），其余照常。这是"并行任务各自隔离"的健壮写法；
    • 加权分：Σ(score × weight)，因为权重和为 1.0，结果天然落在 0–100。

    4.5.4 两个辅助函数¶

    • _build_structured_summary(structured)：把 4.4 提取的结构化简历，浓缩成几行摘要（姓名/意向/学历/技能/项目数）。评审时传摘要而非全文，省 token、也让 LLM 抓重点。
    • _empty_dimension_score(dim)：维度评审失败时的降级结果——给 50 分（中性）、标注"该维度评审失败，建议人工复核"。

    在 4.4 的 nodes.py 基础上，**追加**以下内容（维度表、节点、两个辅助函数）。同时记得在文件顶部的 import 里补上 DimensionScore：

# ──────────────────────────────────────────────────────────────
# 六维度定义（名称 / 权重 / 评分侧重）。权重之和 = 1.0
# ──────────────────────────────────────────────────────────────
SIX_DIMENSIONS = [
    {"key": "project_depth",  "name": "项目深度",   "weight": 0.30,
     "focus": "项目描述是否有量化数据、技术选型理由、个人贡献、难点解决"},
    {"key": "tech_match",     "name": "技术匹配度", "weight": 0.25,
     "focus": "技术栈是否与目标岗位匹配，技能描述是否有层次（熟练/了解/掌握）"},
    {"key": "expression",     "name": "表达规范性", "weight": 0.15,
     "focus": "动词开头、STAR 结构、无错别字、无主语省略歧义"},
    {"key": "structure",      "name": "简历结构",   "weight": 0.15,
     "focus": "模块完整性、排版逻辑、信息密度、重要内容是否放前面"},
    {"key": "quantification", "name": "量化程度",   "weight": 0.10,
     "focus": "性能指标、用户量、优化幅度等量化数据的使用情况"},
    {"key": "authenticity",   "name": "真实可信度", "weight": 0.05,
     "focus": "表述是否夸大、技术深度描述是否与经验年限匹配、时间线是否合理"},
]


# ──────────────────────────────────────────────────────────────
# 节点⑤：run_six_dimensions —— 六维度并行评审
# ──────────────────────────────────────────────────────────────
async def run_six_dimensions_node(state: ResumeState) -> dict:
    """六维度并行评审：同时发 6 个 LLM 请求，各自独立评分，最后算加权综合分。"""
    raw_text   = state["raw_text"]
    structured = state.get("structured") or {}
    structured_summary = _build_structured_summary(structured)   # 精简摘要，省 token

    async def review_one_dimension(dim: dict) -> dict:
        """评审单个维度，返回 DimensionScore dict（内含 2 次尝试）。"""
        prompt_template = DIMENSION_REVIEW_PROMPTS.get(dim["key"], "")
        if not prompt_template:                       # 找不到对应提示，直接降级
            return _empty_dimension_score(dim)

        prompt = prompt_template.format(
            resume_text=raw_text[:3000],              # 原文前 3000 字
            structured_summary=structured_summary,
            focus=dim["focus"],
        )

        for attempt in range(2):                      # 最多尝试 2 次
            try:
                structured_llm = get_structured_llm("resume", DimensionScore)
                result: DimensionScore = await structured_llm.ainvoke([
                    SystemMessage(content=SYSTEM_PROMPT),
                    HumanMessage(content=prompt),
                ])
                d = result.model_dump()
                d["dimension"] = dim["name"]          # 代码层覆盖：中文维度名
                d["weight"]    = dim["weight"]        # 代码层覆盖：权重
                d["key"]       = dim["key"]
                return d
            except Exception as e:
                if attempt == 0:                      # 第一次失败：等 1 秒后重试
                    logger.warning("six_dimensions.dimension_retry", dimension=dim["name"], error=str(e))
                    await asyncio.sleep(1)
                else:                                 # 第二次仍失败：降级
                    logger.warning("six_dimensions.dimension_failed", dimension=dim["name"], error=str(e))
                    return _empty_dimension_score(dim)

    # 六维度并行：先建 6 个协程，再用 gather 一起跑、等全部完成
    tasks = [review_one_dimension(dim) for dim in SIX_DIMENSIONS]
    dimension_scores = await asyncio.gather(*tasks)

    # 加权综合分 = Σ(得分 × 权重)；权重和为 1.0，结果落在 0-100
    weighted_score = sum(d["score"] * d["weight"] for d in dimension_scores)

    logger.info("six_dimensions.done",
                weighted_score=round(weighted_score, 2),
                scores={d["key"]: d["score"] for d in dimension_scores})

    return {
        "dimension_scores": list(dimension_scores),
        "weighted_score":   round(weighted_score, 2),
    }


# ── 辅助：从结构化数据构建简洁摘要（供评审 Prompt 使用，省 token）──
def _build_structured_summary(structured: dict) -> str:
    lines = []
    if structured.get("name"):
        lines.append(f"姓名：{structured['name']}")
    if structured.get("target_position"):
        lines.append(f"求职意向：{structured['target_position']}")
    if structured.get("education"):
        edu = structured["education"][0]
        lines.append(f"最高学历：{edu.get('school','')} {edu.get('major','')} {edu.get('degree','')}")
    if structured.get("skills_list"):
        lines.append(f"技术栈：{', '.join(structured['skills_list'][:10])}")
    if structured.get("projects"):
        proj_names = [p.get("name", "") for p in structured["projects"]]
        lines.append(f"项目数量：{len(structured['projects'])} 个（{', '.join(proj_names[:3])}）")
    if structured.get("work_experience"):
        lines.append(f"工作经历：{len(structured['work_experience'])} 段")
    return "\n".join(lines) if lines else "（结构化提取失败，请基于原文评审）"


# ── 辅助：维度评审失败时的降级结果（给中性 50 分 + 标记复核）──
def _empty_dimension_score(dim: dict) -> dict:
    return {
        "key":         dim["key"],
        "dimension":   dim["name"],
        "score":       50,
        "weight":      dim["weight"],
        "issues":      ["该维度评审失败，建议人工复核"],
        "suggestions": [],
    }

    4.5.6 ✅ 测试（离线，用假 LLM 验证并行/加权/降级）¶

    并行、加权、降级这些**逻辑**可以用一个"假 LLM"在不联网的情况下完整验证。把下面这段作为测试脚本运行（或放进 nodes.py 的 if __name__）：

    import asyncio, time
import backend.agents.resume.nodes as N
from backend.agents.resume.state import DimensionScore

class FakeLLM:
    """假模型：sleep 0.1s 模拟网络，返回固定分数（或抛错模拟失败）。"""
    def __init__(self, score, fail=False):
        self.score, self.fail = score, fail
    async def ainvoke(self, messages):
        await asyncio.sleep(0.1)
        if self.fail:
            raise RuntimeError("模拟维度失败")
        return DimensionScore(score=self.score)

state = {"raw_text": "简历原文 " * 50,
         "structured": {"name": "张三", "skills_list": ["Java", "Redis"], "projects": [{"name": "电商系统"}]}}

# ① 全部返回 80 分 → 验证并行（计时）+ 加权
N.get_structured_llm = lambda agent_type, schema: FakeLLM(80)
t = time.perf_counter()
r = asyncio.run(N.run_six_dimensions_node(state))
print("① 维度数:", len(r["dimension_scores"]))
print("   加权综合分:", r["weighted_score"])
print("   耗时:", round(time.perf_counter() - t, 2), "秒")

# ② 全部失败 → 验证降级
N.get_structured_llm = lambda agent_type, schema: FakeLLM(0, fail=True)
r2 = asyncio.run(N.run_six_dimensions_node(state))
print("② 全失败降级 → 加权分:", r2["weighted_score"], "| issues:", r2["dimension_scores"][0]["issues"])

    实际输出：

    ① 维度数: 6
   加权综合分: 80.0
   耗时: 0.1 秒
② 全失败降级 → 加权分: 50.0 | issues: ['该维度评审失败，建议人工复核']

    三个关键点都验证了：

    • 并行：6 个各 sleep 0.1 秒的请求，总耗时**只有 0.1 秒**（若串行会是 0.6 秒）——asyncio.gather 确实把它们同时跑了；
    • 加权：全 80 分 × 权重和 1.0 = 80.0，加权计算正确；
    • 降级：全部失败时每维度兜底 50 分、标记需复核，整个节点不崩。

    真实评分（接 DeepSeek）每个维度会返回不同分数，加权出一个真实综合分。逻辑已验证，接上 Key 即可看到真实评审效果。

    章节总结¶

    本节我们写好了简历 Agent 的性能核心 run_six_dimensions：

    • 并行：6 个独立维度用 asyncio.gather 同时评，总耗时从"6 次相加"压成"取最慢的一次"（回顾 2.1）。
    • 维度表驱动：SIX_DIMENSIONS 定义名称/权重/侧重；维度名和权重由代码填，LLM 只管打分。
    • 加权综合分：Σ(得分 × 权重)，权重和为 1.0。
    • 健壮性：单维度内置 2 次重试 + 失败降级（50 分），各维度互相隔离、互不影响。
    • 测试：用假 LLM 离线验证了并行（计时）、加权、降级三件事。
