    4.6 问题诊断与整体评价¶

    学习目标¶

    • 掌握 diagnose_issues 节点：汇总维度问题 → Think 前置推理 → 生成结构化问题清单 → 按优先级排序
    • 掌握 generate_summary 节点：综合一切生成整体评价
    • 理解"先想后答"（Think）在结构化输出前的作用
    • 写完即测：离线验证优先级排序、降级、评价生成

    📁 本节要修改的文件：

    文件路径 作用 进度
    backend/agents/resume/nodes.py 追加 diagnose_issues 和 generate_summary 节点 🔧 本节追加

    4.6.1 这两步做什么¶

    到 4.5 为止，我们有了六维度评分，但每个维度的问题还是零散的。这两个节点负责"收口"：

    • diagnose_issues（问题诊断）：把六维度里发现的问题**汇总、去重、定位、标优先级**，生成一份用户能直接照着改的清单。
    • generate_summary（整体评价）：综合结构化信息、评分、问题，生成**面向学员的总结**（亮点、核心改进、综合评语、岗位匹配度）。

    4.6.2 diagnose_issues：问题诊断¶

    这个节点有四步：① 汇总各维度问题 → ② Think 前置推理 → ③ 结构化生成问题清单 → ④ 按优先级排序。

    ① 汇总各维度的原始问题¶

    先把六维度各自发现的 issues 收集起来，作为诊断的输入素材：

    all_raw_issues = []
for dim in dimension_scores:
    for issue_text in dim.get("issues", []):
        all_raw_issues.append(f"[{dim['dimension']}] {issue_text}")
raw_issues_text = "\n".join(f"- {i}" for i in all_raw_issues) or "（暂无）"

    ② Think 前置推理（"先想后答"）¶

    直接让 LLM 输出结构化清单，容易只见树木。所以**先用一段自由文本让它做宏观分析**（回顾 4.3 的 DIAGNOSE_THINK_PROMPT），再把这段思考作为上下文喂给下一步：

    reasoning_trace = ""
try:
    think_prompt = DIAGNOSE_THINK_PROMPT.format(...)
    think_llm = get_llm("resume", temperature=0)          # 普通模型（非结构化）
    think_resp = await think_llm.ainvoke([HumanMessage(content=think_prompt)])
    # 兼容不同返回：优先 .text，否则用 .content
    reasoning_trace = (
        think_resp.text if hasattr(think_resp, "text") and not callable(think_resp.text)
        else str(think_resp.content)
    ).strip()
except Exception as e:
    logger.warning("diagnose_think.failed", error=str(e))   # Think 失败不影响主流程

    注意 Think 这一步**包在 try 里、失败也不报错**——它是"锦上添花"的增强，拿不到推理就用空字符串，主诊断照常进行。这种"增强可失败、主流程不依赖"的写法很常见。

    ③ 结构化生成问题清单¶

    把 Think 结果拼进提示词，调结构化 LLM 生成 IssueList（回顾 4.2 的包装类）：

    prompt = DIAGNOSE_ISSUES_PROMPT.format(...) + think_context
try:
    structured_llm = get_structured_llm("resume", IssueList)
    result: IssueList = await structured_llm.ainvoke([SystemMessage(...), HumanMessage(content=prompt)])
    issues = [item.model_dump() for item in result.items]      # 列表里每个 IssueItem 转 dict
except Exception as e:
    # 降级：直接用各维度问题，统一标 medium
    issues = [{"priority": "medium", "dimension": dim["dimension"], "description": issue,
               "location": "简历全文", "suggestion": "请参考评审建议修改"}
              for dim in dimension_scores for issue in dim.get("issues", [])]

    ④ 按优先级排序¶

    最后把问题按 high → medium → low 排序，让最该改的排在最前：

    priority_order = {"high": 0, "medium": 1, "low": 2}
issues.sort(key=lambda x: priority_order.get(x.get("priority", "low"), 2))

    sort(key=...) 用一个"优先级→数字"的映射当排序键：high 映射成 0 排最前，low 映射成 2 排最后。这是给非数值字段排序的常用技巧。

    4.6.3 generate_summary：整体评价¶

    最后一个 LLM 节点。它把前面所有结果"喂"给 LLM，生成面向学员的总结。关键是**先从 issues 里挑出高优先级问题、把维度分整理成文字**，再填进提示词：

    # 挑出高优先级问题（最多 5 条）
high_issues = [i["description"] for i in issues if i.get("priority") == "high"][:5]
# 六维度得分整理成文字
scores_text = "\n".join(f"- {d['dimension']}：{d['score']}分（权重{int(d['weight']*100)}%）"
                        for d in dimension_scores)

prompt = GENERATE_SUMMARY_PROMPT.format(
    structured_summary=_build_structured_summary(structured),
    scores_summary=scores_text,
    weighted_score=round(weighted_score, 1),
    high_issues="\n".join(f"- {i}" for i in high_issues) or "（无高优先级问题）",
    target_position=structured.get("target_position", "后端开发"),
)
structured_llm = get_structured_llm("resume", ResumeSummary)   # 输出目标：ResumeSummary

    和 4.4 的提取节点一样，generate_summary 也要防"结构化输出返回 None"——而且它**最容易中招**：它的提示词是"请生成整体评价**报告**"这种生成型措辞，DeepSeek 有时会直接用文字回复、不调用工具，于是 ainvoke 返回 None。所以这里同样**判 None + 重试 2 次**，两次都失败才用默认评价兜底，保证总有结果。

    ⚠️ 真实踩坑（与 4.4 同源）：with_structured_output 偶发返回 None，在"写报告/评价"这类生成型提示上概率更高。处理方式固定三招：判 None、重试、必要时退化为 json-mode 手动解析。绝不能假设它每次都返回对象。

    4.6.4 追加到 backend/agents/resume/nodes.py¶

    在 nodes.py 末尾**追加**这两个节点。顶部 import 需补上 IssueList、ResumeSummary、get_llm，以及三个提示词：

    # ── nodes.py 顶部 import 补充 ──
# from backend.agents.resume.state import (..., IssueList, ResumeSummary)
# from backend.agents.resume.prompts import (..., DIAGNOSE_ISSUES_PROMPT,

# ──────────────────────────────────────────────────────────────
# 节点⑥：diagnose_issues —— 逐条问题诊断
# ──────────────────────────────────────────────────────────────
async def diagnose_issues_node(state: ResumeState) -> dict:
    """汇总六维度问题，Think 前置推理后生成带优先级的诊断清单，并排序。"""
    dimension_scores = state.get("dimension_scores", [])
    raw_text         = state["raw_text"]
    structured       = state.get("structured") or {}

    # ① 汇总各维度已发现的问题文本
    all_raw_issues = []
    for dim in dimension_scores:
        for issue_text in dim.get("issues", []):
            all_raw_issues.append(f"[{dim['dimension']}] {issue_text}")
    raw_issues_text = "\n".join(f"- {i}" for i in all_raw_issues) or "（暂无）"

    # ② Think 前置推理（自由文本宏观分析；失败不影响主流程）
    reasoning_trace = ""
    try:
        dimension_scores_summary = "\n".join(
            f"- {d['dimension']}：{d['score']}分 — 问题：{', '.join(d.get('issues', [])[:2])}"
            for d in dimension_scores
        )
        think_prompt = DIAGNOSE_THINK_PROMPT.format(
            dimension_scores_summary=dimension_scores_summary,
            raw_issues=raw_issues_text,
        )
        think_llm = get_llm("resume", temperature=0)          # 普通模型（非结构化）
        think_resp = await think_llm.ainvoke([HumanMessage(content=think_prompt)])
        # 兼容不同版本返回：优先 .text（且不是方法），否则用 .content
        reasoning_trace = (
            think_resp.text if hasattr(think_resp, "text") and not callable(think_resp.text)
            else str(think_resp.content)
        ).strip()
        logger.debug("diagnose_think.done", dimensions=len(dimension_scores))
    except Exception as e:
        logger.warning("diagnose_think.failed", error=str(e))

    # 把 Think 结果作为附加上下文拼到诊断提示后面
    think_context = f"\n\n【诊断前宏观分析】\n{reasoning_trace}" if reasoning_trace else ""

    # ③ 结构化生成问题清单（IssueList）
    prompt = DIAGNOSE_ISSUES_PROMPT.format(
        resume_text=raw_text[:3000],
        structured_summary=_build_structured_summary(structured),
        raw_issues=raw_issues_text,
    ) + think_context

    try:
        structured_llm = get_structured_llm("resume", IssueList)
        result: IssueList = await structured_llm.ainvoke([
            SystemMessage(content=SYSTEM_PROMPT),
            HumanMessage(content=prompt),
        ])
        issues = [item.model_dump() for item in result.items]    # 每条 IssueItem 转 dict
    except Exception as e:
        logger.warning("diagnose_issues.failed", error=str(e))
        # 降级：直接用各维度问题，统一标 medium
        issues = [
            {"priority": "medium", "dimension": dim["dimension"], "description": issue,
             "location": "简历全文", "suggestion": "请参考评审建议修改"}
            for dim in dimension_scores
            for issue in dim.get("issues", [])
        ]

    # ④ 按优先级排序：high(0) → medium(1) → low(2)
    priority_order = {"high": 0, "medium": 1, "low": 2}
    issues.sort(key=lambda x: priority_order.get(x.get("priority", "low"), 2))

    logger.info("diagnose_issues.done",
                total=len(issues),
                high=sum(1 for i in issues if i.get("priority") == "high"))
    return {"issues": issues}


# ──────────────────────────────────────────────────────────────
# 节点⑦：generate_summary —— 整体评价生成
# ──────────────────────────────────────────────────────────────
async def generate_summary_node(state: ResumeState) -> dict:
    """综合结构化信息、六维度评分、问题清单，生成面向学员的整体评价。"""
    structured       = state.get("structured") or {}
    dimension_scores = state.get("dimension_scores", [])
    issues           = state.get("issues", [])
    weighted_score   = state.get("weighted_score", 0.0)

    # 挑出高优先级问题（最多 5 条）
    high_issues = [i["description"] for i in issues if i.get("priority") == "high"][:5]
    high_issues_text = "\n".join(f"- {i}" for i in high_issues) or "（无高优先级问题）"

    # 六维度得分整理成文字
    scores_text = "\n".join(
        f"- {d['dimension']}：{d['score']}分（权重{int(d['weight'] * 100)}%）"
        for d in dimension_scores
    )

    prompt = GENERATE_SUMMARY_PROMPT.format(
        structured_summary=_build_structured_summary(structured),
        scores_summary=scores_text,
        weighted_score=round(weighted_score, 1),
        high_issues=high_issues_text,
        target_position=structured.get("target_position", "后端开发"),
    )

    structured_llm = get_structured_llm("resume", ResumeSummary)   # 输出目标：ResumeSummary

    summary_dict = None
    for attempt in range(2):                          # 最多尝试 2 次（结构化输出偶发返回 None）
        try:
            result = await structured_llm.ainvoke([
                SystemMessage(content=SYSTEM_PROMPT),
                HumanMessage(content=prompt),
            ])
            if result is None:                        # 模型没调用工具、用文字回复 → None
                raise ValueError("structured output returned None")
            summary_dict = result.model_dump()
            break
        except Exception as e:
            if attempt == 0:
                logger.warning("generate_summary.retry", error=str(e))
                await asyncio.sleep(1)
            else:
                logger.warning("generate_summary.failed", error=str(e))

    if summary_dict is None:                          # 两次都失败 → 用默认评价兜底
        summary_dict = {
            "highlights":        ["简历内容已完整提交"],
            "core_improvements": high_issues[:2] if high_issues else ["请参考各维度建议修改"],
            "overall_comment":   f"综合评分 {round(weighted_score, 1)} 分，请参考各维度详细反馈。",
            "fit_assessment":    "与目标岗位匹配度评估暂不可用",
        }

    logger.info("generate_summary.done",
                highlights_count=len(summary_dict.get("highlights", [])))
    return {"summary": summary_dict}

    4.6.5 ✅ 测试（离线，用假 LLM 验证排序/降级/生成）¶

    排序、降级、评价生成这些逻辑可以用假 LLM 离线验证。运行测试脚本：

    import asyncio
from types import SimpleNamespace
import backend.agents.resume.nodes as N
from backend.agents.resume.state import IssueItem, IssueList, ResumeSummary

class FakeThink:                       # 假 Think 模型
    async def ainvoke(self, messages):
        return SimpleNamespace(content="宏观分析：项目深度不足是核心短板",
                               text="宏观分析：项目深度不足是核心短板")

class FakeStructured:                  # 假结构化模型（可返回对象或抛错）
    def __init__(self, obj=None, fail=False): self.obj, self.fail = obj, fail
    async def ainvoke(self, messages):
        if self.fail: raise RuntimeError("模拟LLM失败")
        return self.obj

state = {
    "raw_text": "简历原文 " * 50,
    "structured": {"name": "张三", "target_position": "后端", "projects": [{"name": "电商"}]},
    "dimension_scores": [
        {"key": "project_depth", "dimension": "项目深度", "score": 60, "weight": 0.3, "issues": ["项目描述空洞"]},
        {"key": "tech_match", "dimension": "技术匹配度", "score": 70, "weight": 0.25, "issues": ["技能无层次"]},
    ],
    "weighted_score": 64.0,
}

# ① diagnose 成功：故意乱序优先级，验证排序 high→medium→low
N.get_llm = lambda *a, **k: FakeThink()
mixed = IssueList(items=[
    IssueItem(priority="low",    dimension="结构",     description="证书未列",   location="末尾",       suggestion="补充"),
    IssueItem(priority="high",   dimension="项目深度", description="无量化",     location="项目-电商",  suggestion="加QPS"),
    IssueItem(priority="medium", dimension="表达",     description="非动词开头", location="项目第1句",  suggestion="改写"),
])
N.get_structured_llm = lambda a, schema: FakeStructured(obj=mixed)
r = asyncio.run(N.diagnose_issues_node(state))
print("① 排序后优先级:", [i["priority"] for i in r["issues"]])

# ② diagnose 降级：结构化 LLM 失败 → 用维度问题兜底
N.get_structured_llm = lambda a, schema: FakeStructured(fail=True)
r2 = asyncio.run(N.diagnose_issues_node(state))
print("② 降级后问题数:", len(r2["issues"]), "| 全 medium:", all(i["priority"] == "medium" for i in r2["issues"]))

# ③ generate_summary 成功
summary_obj = ResumeSummary(highlights=["有项目经历"], core_improvements=["补充量化"],
                            overall_comment="中等水平", fit_assessment="较匹配")
N.get_structured_llm = lambda a, schema: FakeStructured(obj=summary_obj)
state["issues"] = r["issues"]
r3 = asyncio.run(N.generate_summary_node(state))
print("③ summary 字段:", list(r3["summary"].keys()), "| fit:", r3["summary"]["fit_assessment"])

    实际输出：

    ① 排序后优先级: ['high', 'medium', 'low']
② 降级后问题数: 2 | 全 medium: True
③ summary 字段: ['highlights', 'core_improvements', 'overall_comment', 'fit_assessment'] | fit: 较匹配

    验证了：

    • ① 排序：无论 LLM 返回什么顺序，最终都按 high→medium→low 排好；
    • ② 降级：结构化生成失败时，回退到"用各维度问题拼清单"，整个节点不崩；
    • ③ 评价：generate_summary 正确产出四字段评价。

    真实接 DeepSeek 时，Think 会输出真实宏观分析，问题清单会有具体定位和建议，整体评价会针对简历内容生成。逻辑已离线验证，接 Key 即见真实效果。

    章节总结¶

    本节我们写好了简历 Agent 的"收口"两节点：

    • diagnose_issues：汇总维度问题 → Think 前置推理（可失败、不依赖）→ 结构化生成 IssueList → 按优先级排序（sort(key=映射)）→ 失败降级为维度问题清单。
    • generate_summary：挑高优先级问题、整理维度分，生成 ResumeSummary 整体评价，失败有默认兜底。
    • 测试：离线验证了优先级排序、降级、评价生成。

    到此 8 个节点里的"业务"节点都写好了。下一节 4.7 持久化与图装配，我们写最后一个节点 save_results（把结果写进 resume_reviews 的 JSONB 字段）和 graph.py（把 8 个节点装配成图），并给出 nodes.py 的**最终完整版**。
