    5.1 RAG 问答系统：全景与架构¶

    学习目标¶

    • 理解 RAG 是什么、为什么需要它，以及它的两个阶段（离线建库 / 在线查询）
    • 看懂智能问答 Agent 的完整执行流程图（12 节点 + 3 个条件分支 + 记忆）
    • 对比第四章，理解从"直线图"到"带分支 + 记忆的图"的跃迁
    • 预览本章要用到的 7 项 RAG 关键技术
    • 了解本章规划，能自己核对"章节顺序是否贴着流程走"

    🧠 这是项目里最复杂的 Agent。 它不再是一条直线，而是有意图分流、查询改写、混合检索、重排序、置信度路由、Web 兜底、多轮记忆。别担心——本章会严格**顺着它实际运转的流程**一步步拆，每一步都先讲清"为什么需要它"。

    5.1.1 RAG 是什么，为什么需要¶

    大模型有三个天生的局限：会编（幻觉）、不知道新东西（知识截止）、不知道你的私有内容（比如你这门课的讲义）。直接问 LLM "我们课程项目里 LSTM 那层怎么定义的"，它只能瞎猜。

    RAG（Retrieval-Augmented Generation，检索增强生成） 的思路很直接：先去知识库里检索相关内容，再把这些内容连同问题一起交给 LLM，让它"看着资料回答"。 这样回答有据可依、可溯源，也能覆盖私有知识。

    RAG 天然分成两个阶段，理解这两个阶段是理解整章的关键：

    【阶段一：离线建库】（事先做好，把知识灌进向量库）
   课程文档(PDF/Word) → 切成小块(chunk) → 每块算成向量(嵌入) → 存入向量库(Milvus)

【阶段二：在线查询】（学员每次提问时实时发生）
   学员提问 → 问题算成向量 → 去向量库检索最相关的块 → 重排 → 交给 LLM 生成回答

    💡 一句话记忆：先把书放进书架（建库），才能查书（查询）。 本章前半部分（5.2–5.10）做"建库"，后半部分（5.11 起）做"查询"。

    5.1.3 对比第四章：从直线到分支 + 记忆¶

    第四章的简历 Agent 是一条直线（8 个节点顺次走完）。本章多了两样关键东西，正好对应 2.4 学过、但第四章没用上的特性：

    特性 第四章简历 Agent 本章问答 Agent
    流程形态 一条直线 带分支（按问题类型、按置信度走不同路径）
    分支实现 无 条件边 add_conditional_edges（回顾 2.4）
    多轮记忆 不需要（一次性任务） 需要（连续问答要记得上文）
    记忆实现 无 checkpointer 挂 checkpointer（MemorySaver，回顾 2.4）
    节点数量 8 个 12 个
    依赖模型 DeepSeek API（1 个） DeepSeek API + 3 个进程内本地模型

    换句话说，第四章你掌握了"搭直线图"，本章你将掌握"搭带分支和记忆的图"——这才是 LangGraph 真正的威力所在。

    5.1.4 本章会用到的 7 项 RAG 关键技术¶

    这个 Agent 之所以复杂，是因为它在朴素 RAG（"检索→喂给LLM"）的基础上叠了一系列提升效果的技术。先混个脸熟，后面各节会逐一实现：

    1. 意图分类：先判断问题是"闲聊/通用"还是"课程专业问题"，通用问题直接答、不浪费检索（→ 5.12）
    2. HyDE（假设文档）：问题太模糊时，先让 LLM 生成一段"假设的答案文档"，用它去检索，召回更准（→ 5.12）
    3. Multi-Query（多查询改写）：问题太宽泛时，拆成几个具体子问题分别检索，扩大召回（→ 5.12）
    4. 稠密 + 稀疏混合检索：BGE-M3 同时产出"语义向量（稠密）"和"关键词向量（稀疏）"，两路检索再融合（RRF），兼顾语义和关键词（→ 5.4、5.6）
    5. 重排序（Reranker）：召回的候选用更精的模型重新打分排序，把最相关的顶上来（→ 5.7）
    6. 置信度路由 + Web 兜底：检索结果够好就基于知识库答；不够好就联网搜索或让 LLM 直答（→ 5.13、5.14）
    7. 多轮记忆 + 摘要压缩：记住对话历史；太长了就压缩成摘要，省 token（→ 5.9、5.14）

    章节总结¶

    本节从全景上认识了最复杂的 Agent——RAG 智能问答系统：

    • RAG 是什么：先检索知识库、再让 LLM "看着资料回答"，解决幻觉 / 知识截止 / 私有知识三大局限
    • 两个阶段：离线建库（文档 → 分块 → 嵌入 → 存库）+ 在线查询（提问 → 检索 → 重排 → 生成）
    • 完整流程图：12 节点 + 3 个条件分支 + 记忆，本章逐个方框实现
    • 相比第四章：从直线图跃迁到"条件边分支 + checkpointer 记忆"的图
    • 7 项关键技术：意图分类、HyDE、Multi-Query、混合检索、重排序、置信度路由、多轮记忆
