# 0.1 API 获取

## 1. 阿里云百炼

参考文档：`【应用开发实战-2】API调用+LLM部署并暴露接口服务`

操作入口：

1. 进入阿里云百炼控制台。
2. 在左侧导航进入模型服务相关菜单。
3. 打开调用凭据管理页面。
4. 点击创建按钮生成新的调用凭据。
5. 将生成结果按项目 `.env` 示例写入对应配置项。

> 注意：截图中页面包含真实或半遮蔽的凭据信息，本文不记录任何具体值。

## 2. Bocha Search API

官网入口：<https://open.bochaai.com/>

操作步骤：

1. 打开 Bocha AI 开放平台。
2. 点击右上角登录/注册入口。
3. 进入控制台后创建搜索服务调用凭据。
4. 将凭据写入项目环境配置中的搜索服务配置项。

## 3. Docmind API

入口：<https://homenew.console.aliyun.com/home/dashboard/ProductAndService>

操作步骤：

1. 进入阿里云控制台。
2. 在右上角账号菜单中进入访问凭据或安全凭据相关页面。
3. 创建或查看用于调用 Docmind 相关服务的凭据。
4. 在“我的服务”页面确认已开通服务，并查看对应调用信息。
5. 将服务调用信息按 `.env` 示例配置到项目中。

## 4. 招投标 API

入口：<https://market.aliyun.com/detail/cmapi00063550?spm=5176.29867242_210807074.0.0.44e83e7eBT13qT#sku=yuncode5755000003>

操作提示：

1. 打开阿里云市场对应接口商品页。
2. 点击右侧的免费试用入口。
3. 开通后在控制台查看该服务的调用信息。
4. 将应用调用凭据、调用码等信息写入项目配置。

> 安全说明：本文只记录获取入口和操作位置，不保存任何真实调用凭据、调用码或密钥截图。
