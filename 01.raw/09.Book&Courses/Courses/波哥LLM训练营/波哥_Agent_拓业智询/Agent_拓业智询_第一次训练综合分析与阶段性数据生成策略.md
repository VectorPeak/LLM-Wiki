# 【Deepresearch训练】第一次训练综合分析与阶段性数据生成策略

## 一、背景与范围

本次“第一次训练”指：使用 `data/train_v3_200_clean.jsonl`（清洗后 187 条样本）进行 1 个 epoch 训练，并用 `scripts/full_eval.py` 在 10 个通用测试用例上做格式、工具调用、工具准确性、答案准确性与完整度评估。

- 模型：`qwen3_0.6b` + LoRA
- 训练参数：`epoch=1`，`max_length=8192`，`gradient_accumulation=8`
- 评估：基线模型 vs 训练后模型对比

## 二、综合结论

结论要点：

1. **格式能力提升显著**：训练后几乎稳定输出 `<think> + <tool_call>{JSON}`。
2. **工具选择仍偏弱**：简单问题仍倾向使用 `search`，工具调用准确率提升有限。
3. **答案准确性与完整度不足**：小样本导致内容能力提升有限，仍需要大规模数据支撑。

## 三、评估结果摘要

- 格式得分：`4/20 -> 20/20`（大幅提升）
- 工具选择正确：`0/10 -> 2/10`（小幅提升）
- 答案准确：`0/10 -> 3/10`
- 答案完整度（均值）：`0% -> 23%`

> 解释：训练后模型在“结构化输出”上明显学会了格式，但“工具是否该用、用哪一个，以及答案是否准确完整”仍不稳定，典型原因是样本规模偏小、指令分布与真实推理分布差异较大。

## 四、典型案例（Case）

### Case 1：格式修复成功，但工具选择错误

- 问题：什么是人工智能？
- 期望：直接 `finish`（常识题）
- 模型表现：输出正确格式，但调用 `search`
- 分析：训练数据中“常识直接 finish”的比例仍不足，模型倾向“默认搜索”。

### Case 2：计算题工具选择改善

- 问题：50×20 等于多少？
- 期望：`calculator` 或直接 `finish`
- 模型表现：调用 `calculator`，工具选择正确，但答案完整性一般
- 分析：说明“工具调用结构”学到了，但 `finish` 输出的稳定性仍需要多样本。

### Case 3：事实题答案准确性提升

- 问题：水的化学式是什么？
- 期望：`finish` + 正确答案
- 模型表现：训练后能输出正确答案，且结构稳定
- 分析：说明对“通用事实”有一定迁移，但仍不是稳定现象。

## 五、核心问题归因

1. **样本量不足**：187 条对“工具选择策略”学习仍偏少。
2. **分布偏移**：训练数据中 “search/visit 轨迹” 占比过高，导致模型倾向搜索。
3. **输出规范不够强**：虽然 JSON tool_call 规范化完成，但仍存在少量“重复输出”和“finish 缺失”样本。

## 六、阶段性数据生成策略（建议）

### 阶段 1（当前 -> 200）

目标：稳定格式与工具调用结构。

- 样本数：200
- 重点：格式统一（JSON tool_call）、role 对齐（tool）
- 简单题比例：>= 25%（直接 finish）
- 工具分布：search/visit 不超过 60%

### 阶段 2（200 -> 1000）

目标：提升工具选择准确性与答案准确性。

- 样本数：累计 1000（分批生成）
- 强化：
  - 常识题必须直接 finish
  - 计算题优先 calculator
  - 事实题仅在不确定时 search
  - 加入 10% “无需搜索但需引用” 的示例
- 校验：每批次做清洗，保证 `finish` 完整率 > 95%

### 阶段 3（1000 -> 3000）

目标：提升答案准确性与全面性（覆盖更多行业场景）。

- 样本数：累计 3000
- 增强：
  - 引用一致性检查（引用编号与工具输出对齐）
  - visit 类轨迹比例控制在 20% 左右
  - 多样化行业场景（4 行业 × 6 类型）均衡覆盖
- 评估：增加行业场景测试集（20~50 题）

## 七、执行建议

1. **每批次生成后都做“规范化 + 清洗”**

保持数据结构一致性，确保 `finish` 完整率与引用完备率。

2. **单独加入“工具选择训练集”**

例如：常识题/计算题明确标注 `finish` 或 `calculator`，减少模型默认 `search`。

3. **保持分布均衡**

`industry × question_type` 采用轮询采样，避免偏科。

4. **训练-评估闭环**

每 200~300 条做一次小训练 + `full_eval`，观察工具选择与答案正确率趋势。
