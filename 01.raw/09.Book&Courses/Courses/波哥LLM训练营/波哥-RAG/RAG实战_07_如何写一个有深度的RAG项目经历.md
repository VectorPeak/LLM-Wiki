## 1. 明确项目背景与动机

- **问题陈述**：说明当前大模型在特定领域存在的局限（如知识更新滞后、幻觉问题等），以及为何选择 RAG 方法来弥补这些不足。在工业场景中，主要以下 3 个原因：

- 知识库的即时更新：大模型的训练数据是有时效性的，所以外挂知识库

## 项目经历

### RAG 问答系统开发与优化（金融保险领域）　　　　　　　　　　　　2024.06 - 2025.12

- **项目背景**：负责构建面向金融保险业务的检索增强生成（RAG）问答系统，整合 5000+ 份多模态文档（PDF、PPT、扫描图片、视频字幕等），为 XX 金融公司员工提供基于本地知识库的即时问答服务。

- **主要挑战**：
  1. **多格式文档解析**：文档格式多样，部分 PDF 为扫描版，需要高保真 OCR；大量表格、流程说明和 PPT 幻灯片需提取章节层次和可检索文本。
  2. **检索准确率不足**：针对同义词、专业术语和长尾问题，通用向量模型难以处理；同时简单的关键词检索（BM25）漏检率高。
  3. **多轮对话连贯性**：用户跟进提问常使用代词（“这个怎么申请？”），系统需结合上下文才能正确理解意图。
  4. **答案可解释性**：要求对答案出处进行引用，便于核实复杂流程或条款的准确性。

- **核心优化与实现**：

  1. **离线解析及知识库构建**
     - **结构化切分**：结合自然段落、OCR 表格识别、PPT 标题/子弹列表检测，进行智能切分，避免把紧密相关的内容割裂；保留层级标签（章节名、页码、幻灯片编号）便于检索和引用。
     - **OCR 优化**：针对扫描版 PDF，采用 PaddleOCR 对表格区域进行专门检测，配合段落重组算法，最大程度还原文档原貌。

  2. **Query 模块优化**
     - **意图识别**：利用规则 & BERT 分类器 & Prompt Engineering，检测用户是否咨询保险产品、报销制度或营销技巧等，以选取不同检索策略和回答方式。
     - **Query 重写与扩写**：对口语化、错别字、简短问题进行纠错和同义词扩展，如“推销保险” -> “销售保险产品”；提升短查询的检索命中率。
     - **HyDE**：在向量检索前由 LLM 生成“假设文档”以丰富查询语义，捕捉更深层次的同义或关联概念，提高长尾问题的检索效果。

  3. **检索召回模块**
     - **混合检索（BM25 + 向量）**：结合关键词与语义搜索，对短查询优先 BM25，长查询重点向量检索，取并集后再去重，以确保关键字匹配和语义近似都能被召回。
     - **Embedding 微调**：在内部保险领域问答数据上对 BGE/SimCSE 等预训练模型进行对比学习微调，增强对“保单现金价值”“住院医疗险”等术语的语义理解；显著提升领域内语义检索的精度和召回率。
     - **重排（Rerank）**：使用 Cross-Encoder（如微调的 BERT/RoBERTa）对检索候选进行二次打分排序，确保最相关的片段排在前列；多轮测试显示 MRR、NDCG 指标均有 20%+ 提升。
     - **指标评估**：建立测试集及人工标注集，采用 MRR、Precision@K、NDCG@K 等度量检索性能；实验数据表明混合检索 + 嵌入微调 + 重排序，P@3 提升约 30%，用户查询首条命中率明显改善。

  4. **生成阶段优化**
     - **多轮对话上下文管理**：对用户跟进提问进行 Context Injection，将上一轮核心实体（如“寿险产品 ABC”）注入到新问题；或自动将代词替换为明确对象（Query Rewrite）后再检索，保证多轮交互语义连贯。
     - **多模态内容整合**：实现视频字幕、PPT 幻灯片和 PDF 文本的统一向量化与检索，让 LLM 能综合多来源的知识片段回答复杂问题（如既含流程说明，又含时长/时效信息）。
     - **答案引用机制**：在 Prompt 中要求 LLM 对每段内容标注出处（【文档名 第X页】/【PPT第n页】/【视频 00:02:10】），大幅提升答案可解释性与用户信任度。

- **项目成果**：
  1. **显著提升检索准确率**：混合检索 + 微调 + 重排策略在内部测试中，Top5 准确召回率从 65% 提升至 88%，MRR 从 0.50 提高至 0.72。
  2. **多轮问答能力增强**：代词解析与上下文保持使多轮提问准确率提高 25%+；用户在后续追问时能得到连贯、上下文一致的回答。
  3. **系统稳定上线**：该 RAG 系统现已接入企业内部使用，支持销售团队、客服部门、报销财务等多场景查询，月均调用量超过 10 万次，获得正面反馈。
  4. **可解释性与合规**：自动标注引用来源，辅以运营后台日志查看，让合规部门可直接追溯答案出处并执行质检，极大增强了系统可靠性与透明度。

- **技术栈**：
  - NLP/LLM：BERT/RoBERTa、BGE、ChatGPT 等；Sentence-Transformers（对比学习微调）
  - 向量数据库：Elasticsearch（BM25）、Milvus（向量数据库）、Cross-Encoder（Rerank）
  - 文档解析：PyMuPDF/PPTX Python 解析、PaddleOCR、表格识别
  - 评估与监控：MRR、NDCG、Precision/Recall、pytrec_eval、Prometheus/Grafana 日志监控

## 技能

- **深度学习 & Transformer 核心**：熟练掌握 PyTorch/TensorFlow 及主流大模型（GPT、Qwen、Llama 等）原理与训练流程，能结合 LoRA/PEFT 等微调方法快速完成大规模语言模型的开发与迭代。
