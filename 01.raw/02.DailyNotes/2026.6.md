- SVM
	- SVM 是一种监督学习模型，常用于分类。它的核心思想是：在不同类别之间找一条“分界线”，并且让这条线离两边最近的样本都尽可能远。这个距离叫 margin，决定分界线位置的那些最近样本叫 support vectors。SVM 本质上是在追求最大间隔分类，因此通常泛化能力比较好。对于非线性问题，SVM 可以通过 kernel trick 把数据映射到更高维空间，在高维空间中做线性分割，从而在原空间形成非线性分类边界
	
- KL散度以及交叉熵误差的公式+知识蒸馏
	- KL 散度(相对熵)用来衡量两个概率分布之间的差异，表示如果用分布 Q 去近似真实分布 P，会损失多少信息
	- KL 散度可以写成：**KL(P ∥ Q) = ∑ P(x) log(P(x) / Q(x))** 读作：**P 到 Q 的 KL 散度**
	- 交叉熵误差衡量的是：真实分布和模型预测分布之间有多不一致。模型给真实类别的概率越高，交叉熵越小；给真实类别的概率越低，交叉熵越大。H(P, Q) = -∑ P(x) log Q(x)
	- 交叉熵和 KL 散度关系是：
	- **H(P, Q) = H(P) + KL(P ∥ Q)**
	- 如果真实分布 **P** 固定，那么 **H(P)** 是常数。
	
	- 所以训练模型时：
	-  **最小化交叉熵 ≈ 最小化 KL(P ∥ Q)**
	- 也就是让模型预测分布 **Q** 尽量接近真实分布 **P**

	- **H(P)** 是真实分布自己的熵，可以理解成：
	- > **真实世界本身有多不确定。**
	- 它只由真实分布 **P** 决定，和模型预测 **Q** 没关系。

	- 在知识蒸馏中，软标签通常指教师模型经过 softmax 后输出的概率分布。相比 one-hot 硬标签，软标签包含类别之间的相似性信息，也就是 dark knowledge。训练学生模型时，可以把教师分布记为 P，学生分布记为 Q，用交叉熵 H(P,Q) 或 KL(P∥Q) 来约束学生输出接近教师输出。因为 H(P,Q)=H(P)+KL(P∥Q)，而教师分布 P 固定时 H(P) 是常数，所以最小化交叉熵等价于最小化 KL 散度。实际蒸馏中还会引入温度系数 T，使教师输出更平滑，从而暴露更多非正确类别之间的关系，帮助学生学到教师模型的泛化能力。

- DPO/PPO/GRPO的区别--八股
	- **PPO 是 OpenAI 那条路线。** 先训一个 reward model，再用 RL 去优化 policy。每次更新都要让当前 policy 现采新样本，所以是 on-policy。优点是表达力强，理论上多复杂的偏好都能拟合。缺点是要同时跑四个模型——policy、ref、reward、value——显存吃不消，训练也不稳，调参很痛苦，还容易 reward hacking。

	 - **DPO 是 Stanford 那篇论文的路子。** 数学上证明了在 Bradley-Terry 偏好假设下，可以绕过 reward model，直接用偏好对优化 policy。损失函数大概长这样：

	-  数据是预先准备好的，不需要在线采样，所以是 off-policy。只要两个模型，policy 和 ref，显存友好，训练稳，跟 SFT 差不多省心。代价是受离线数据的分布偏移影响，理论上限不如 PPO，β 这个超参对结果还挺敏感。

	 **GRPO 是 DeepSeek 用的。** 算 PPO 的简化版，把 value model 砍了。同一个 prompt 采一组 response，组内相对 reward 当作 advantage，不再单独训一个 value 网络去估。少了一个跟 policy 一样大的 value model，显存省一大截。GRPO 在数学推理这种有明确对错的任务上特别好用——reward 直接看答案对不对，1 分或者 0 分。DeepSeek-R1 用的就是这个。
	
	 简单选一下：数据现成、要稳、要省钱，DPO；reward 复杂、有算力、要做到极致，PPO；reward 是规则可判的(数学、代码)，GRPO。
	
	 **On-policy 和 off-policy 顺手讲清楚。** On-policy 是用当前正在训的模型采的样本来更新这个模型——PPO、GRPO 都是。Off-policy 是用别的模型(或者历史的自己)采的样本来更新当前模型，DPO 就是。实践上 on-policy 数据新鲜但贵，off-policy 数据便宜但有分布偏移。DPO 训到后面效果掉，很多时候就是 policy 已经飘离 ref 太远，那批离线数据相当于过期了。Iterative DPO 就是为了解决这个——训一段时间停下来，用新模型重新采一批数据继续训。
	
	 **Reward hacking。** 模型学会钻 reward 函数的空子，分数刷得很高但没真解决问题。最典型的几个例子：reward 给长回答打高分，模型就开始废话连篇；reward 喜欢礼貌用语，模型每句话开头都"非常感谢您的提问"；代码任务的 reward 是单元测试通过，模型学会写 if input == test_case_1: return answer_1。本质上就是 reward 函数和真实目标对不齐，模型把这个 gap 放大了。防御办法没什么花活——RM 持续迭代、加 KL 约束让 policy 别飘太远、人工抽查、对抗测试。
	
- Transformer自注意力公式当中根号dk的作用
	- 我会从两个角度解释。首先为什么要缩放：因为 attention 的分数是 `QK^T`，如果 key 的维度比较大，点积的数值可能会变大。这个分数直接进 softmax 的话，softmax 容易变得很尖锐，接近 one-hot，导致梯度比较小，所以需要缩放来稳定训练。
	- 然后为什么缩放因子是 `√d_k`：假设 q 和 k 的每一维都是均值 0、方差 1，并且相互独立，那么 `q · k` 是 `d_k` 个随机乘积项的和。每一项方差大约是 1，所以点积的方差是 `d_k`，标准差是 `√d_k`。因此除以 `√d_k` 后，点积结果的方差大约变成 1，softmax 的输入尺度就比较稳定。
	- 如果除以 `d_k`，就会缩放过度，因为点积结果的标准差不是按 `d_k` 增长，而是按 `√d_k` 增长。
	
- Kimi注意力残差的论文
	- 这篇论文主要重新思考了 Transformer 里的 residual connection。传统 PreNorm Transformer 里，每一层都是把前一层 hidden state 和当前层输出直接相加，相当于所有历史层贡献的权重都是固定的 1。这样在模型很深的时候，会出现两个问题：一是 hidden state 的幅度会不断累积，二是每一层真正新增的信息会被越来越多历史信息稀释。

	- Kimi 提出的 Attention Residuals 是把残差路径从“固定相加”改成“可学习选择”。具体来说，当前层不再简单接收所有前面层的均匀累加结果，而是通过 softmax attention 在深度维度上对前面层的输出分配权重。这样模型可以根据输入内容决定更关注哪些浅层或中间层表示。

	- 但 full attention over all previous layers 会带来显存和通信开销，所以论文又提出 Block AttnRes，把层分成 block，只在 block 级别做聚合，降低成本。实验上，他们把它接到 Kimi Linear 结构里，在 48B total / 3B activated 参数模型上训练，发现可以缓解 PreNorm dilution，让输出幅度和梯度分布更均匀，并提升下游任务表现。

**你面试时可以这样讲**  
- 我会把它理解成“把 token 维度上的 attention 思想，迁移到了 layer/depth 维度上”。
- 标准 attention 是让一个 token 从其他 token 里选择有用信息；Attention Residuals 是让一个 layer 从之前的 layer 里选择有用表示。传统 residual 是无条件相加，而 AttnRes 是有选择地聚合。

它的贡献主要有三个：
1. 指出 PreNorm Transformer 里标准残差连接存在 depth-wise dilution，也就是越往深层，单层贡献越容易被历史累积信息稀释。
2. 提出 Full AttnRes，用 attention 权重替代固定残差累加。
3. 提出 Block AttnRes，让这个方法在大模型训练里更实际，避免 full AttnRes 的显存和通信成本过高。

**面试官可能追问**  
问：它和普通 attention 有什么区别？

答：普通 self-attention 是在 sequence/token 维度上做信息选择，Attention Residuals 是在 depth/layer 维度上做信息选择。前者回答“当前 token 应该看哪些 token”，后者回答“当前层应该利用哪些前面层的表示”。

问：为什么不用标准 residual 就好了？

答：标准 residual 的优点是训练稳定、梯度容易传播，但它的聚合方式太固定。所有层输出都默认等权累加，在很深的网络里可能导致 hidden state 不断增长，也会让每层新增信息的边际贡献变小。AttnRes 想保留残差路径的稳定性，同时让信息聚合变得可学习。

问：它有什么代价？

答：Full AttnRes 需要保存并访问所有前面层输出，显存和通信成本都高。论文的工程解法是 Block AttnRes，把层按 block 聚合，在性能收益和训练成本之间做折中。

你可以先按这个顺序学：先懂残差连接和 PreNorm，再懂“固定相加为什么有问题”，最后再看 AttnRes 和 Block AttnRes。这样面试时会显得你不是在背论文，而是在讲一个架构问题是怎么被发现、抽象、工程化解决的。
