# InduClaw - 工业制造智能体平台 | 核心开发

Agent RAG Redis PostgreSQL FastAPI LangGraph SFT DPO RLHF GRPO MBD PLM MES SCADA OPC UA

**背景：** 在某智能制造解决方案公司的 ToB 工业数字化业务线中，系统主要面向离散制造企业、装备制造厂、汽车零部件工厂和工业园区，辅助工艺工程师、设备工程师、质量工程师和一线班组长完成工艺知识查询、MBD 图纸理解、设备故障定位、质量异常分析、巡检维护和生产决策支持。

**目标：** 参考 WiseClaw 的 Agent + Skill 架构，设计并实现面向制造业现场的工业智能体平台，打通 MBD/PLM、MES、SCADA、设备台账、质检记录、工艺规程和维修知识库，支持工艺问答、图纸与 PMI 信息解读、设备故障诊断、异常质量归因、换线准备、点检计划生成和安全合规审查，提升工业知识定位效率、现场问题处理一致性和跨系统数据协同能力。

**过程：**

- 构建工业知识库摄取管线，支持 MBD 三维工艺说明、二维工程图、SOP 作业指导书、设备手册、维修工单、质量检验规范、EHS 制度和产线异常记录的解析、语义分块、Chunk Refinement、Metadata Enrichment 和向量化存储；围绕产品型号、工序、工位、设备编号、物料批次、质量特性、版本号和适用产线建立元数据体系，保证工艺文件变更、设备手册更新和质检标准迭代时的索引一致性。

- 基于 bge-small-zh-v1.5 / bge-m3 完成工业语义召回模型微调，针对工艺术语、设备故障码、检验项目、MBD PMI 标注、BOM 物料描述和维修现象描述优化召回效果；同时基于 Qwen2.5-7B-Instruct 完成工业问答模型 SFT + DPO 微调，提升模型在工艺解释、异常归因、维修建议、风险分级、依据引用和越权拒答场景下的结构化表达能力。

- 使用 LangGraph 编排多 Agent 工作流，拆分为 MBD Parser、Process Retriever、Equipment Diagnosis Agent、Quality Analysis Agent、Maintenance Planner、Safety Checker、Report Writer 等节点，实现图纸/工艺文件解读、异常指标说明、设备故障排查路径、质检缺陷原因分析、备件与工具准备清单、停机影响评估和维修复盘报告生成。

- 接入 MES、PLM、SCADA、ERP、QMS、WMS 和设备 IoT 数据源，通过 MCP connector 对接 Teamcenter/Windchill、SAP、用友/金蝶、Ignition、OPC UA Server、MinIO/Egnyte 等系统；将实时设备状态、历史工单、工艺版本、物料批次、质检数据和知识库文档统一纳入 Agent 可控工具体系。

- 引入 Hermes 自进化机制，将现场高频问答、故障处置闭环、人工修正答案和专家审核意见自动沉淀为案例库、Prompt 优化样本、Skill 更新候选和微调数据候选，实现工业 Agent 能力的持续迭代。

- 参与设计工业 Agent 四层权限与安全审查管道，将工具调用和回答生成依次经过静态规则过滤、工具自检、场景模式兜底和 AI Safety Classifier；结合 RBAC + Workspace 隔离不同工厂、产线、设备、工艺文件、会话记忆和 MCP 工具权限，对跨租户访问、工艺参数泄露、危险操作建议、停机误导、越权查询和不符合 EHS 规范的操作进行动态拦截。

- 引入权限过滤、敏感信息脱敏和检索审计机制，记录用户问题、召回文档、引用 Chunk、工具调用、设备/工单上下文、模型回答、命中分数和耗时，支持质量追溯、工艺变更审计、EHS 复核和生产事故复盘；在生成阶段强制返回文档来源、版本号、工序编号、设备编号、条款编号和原文引用片段，降低模型幻觉风险，保证工程师能够快速定位原始依据。

**成果：** 系统上线后支撑 12000+ 份 MBD 图纸、工艺规程、设备手册和质量标准文档的实时语义检索，工艺/设备知识定位准确率从 68% 提升至 91%，单次工业知识查询 P95 延迟控制在 700ms 内；设备故障排查平均定位时间缩短约 45%，质量异常分析报告生成效率提升约 50%，并支撑多工厂、多产线、多角色的权限隔离与审计追溯。
