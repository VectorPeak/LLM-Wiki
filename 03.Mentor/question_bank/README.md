## Answer Review Rubric

| Grade | Meaning |
|---|---|
| A | Accurate, structured, can handle follow-up |
| B | Mostly correct, minor missing details |
| C | Recognizes the idea but cannot explain deeply |
| D | Memorized fragments, weak causality |
| F | Misunderstood core concept |
