## Entry Points

- `index.md` - vault map and navigation entrypoint
- `AGENTS.md` - Codex operating manual and command routing
- `_CLAUDE.md` - vault conventions and writing rules
- `CRITICAL_FACTS.md` - short always-load context

## Structure

```text
01.raw/        Original source material
02.wiki/       Maintained knowledge graph
03.templates/  Reusable note templates
04.output/     Generated deliverables and intermediate outputs
.codex/        Codex commands, scripts, and reference rules
.obsidian/     Obsidian configuration, plugins, and theme state
Bases/         Obsidian Bases views
boards/        Kanban boards
Logs/          Append-only operation logs
_trash/        Soft-deleted notes
```

This is a working vault, not a traditional application project. Open the
repository root in Obsidian, or work through Codex using `AGENTS.md`.
